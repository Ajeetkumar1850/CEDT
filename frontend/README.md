# CEDTP Frontend

React.js dashboard for monitoring and managing secure file transfers.

## Features

- 📊 Real-time transfer statistics
- 📁 Transfer history and monitoring
- ⬆️ File upload interface
- 🔒 Security feature visualization
- 📈 Performance metrics

## Setup

```bash
cd frontend
npm install
npm start
```

The app will run on http://localhost:3001

## Environment Variables

Create `.env` file:

```
REACT_APP_API_URL=http://localhost:3000
```

## Tech Stack

- React 18
- TypeScript
- Axios for API calls
- Recharts for data visualization
